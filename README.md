# 8th Pay Commission Salary Calculator

A client-side interactive tool designed for Central and State Government employees to project salary revisions under the upcoming 8th Central Pay Commission (CPC).

## 🔗 Live Application
The live utility is hosted and freely accessible here:  
👉 **[8th Pay Commission Online Calculator](https://paycalculator8thpay.blogspot.com/)**

## ⚙️ Calculation Parameters
- **Baseline:** 7th CPC Pay Matrix Levels 1 to 14 (Grade Pay 1800 to 10000).
- **Fitment Factors:** 1.92 (Conservative), 2.15 (Moderate), 2.57 (7th CPC baseline), 2.86 (Projected), and 3.68 (Staff demand).
- **HRA Tiers:** Class X (30%/27%), Class Y (20%/18%), Class Z (10%/9%).
- **Retirement Deductions:** NPS/UPS (10% of Basic + DA) and OPS (GPF estimates).
- **Export:** Browser-rendered printable comparative salary statement.
